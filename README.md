# Rainbow Bracket Pairing

Rainbow colored nesting brackets and matching bracket pair highlighting

## Details
- **Identifier**: `matn.ext.braces`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Rainbow Bracket Pairing**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-braces
```
